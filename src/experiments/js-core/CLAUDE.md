# Section 5: JavaScript 핵심 개념

"설명하세요"가 아니라 "코드로 보여주세요"라고 했을 때 바로 꺼낼 수 있는 수준으로.

## 핵심 개념 연결 지도

```
클로저 ──────────────→ 데이터 은닉, 팩토리, 메모리 누수(Day 9)
이벤트 루프 ──────────→ async/await 이해, React batch 업데이트 이해
this 바인딩 ──────────→ 이벤트 핸들러 버그, 화살표 함수 선택 기준
프로토타입 ──────────→ class 문법 이해, 상속 패턴
비동기 패턴 ──────────→ 에러 핸들링, 병렬 처리, 취소 패턴
```

## 실험 목록

| 실험 | 경로 | 면접 빈출도 |
|------|------|-----------|
| 클로저 & 메모리 | `./closure/` | ★★★ |
| 이벤트 루프 시각화 | `./event-loop/` | ★★★ |
| this 바인딩 4가지 규칙 | `./this-binding/` | ★★★ |
| 프로토타입 체인 | `./prototype/` | ★★ |
| 비동기 패턴 비교 | `./async-patterns/` | ★★★ |

## 구현 방식

각 실험은 **인터랙티브 데모** 형태로 구현:
- 버튼 클릭 → 코드 실행 → 결과 표시
- 왜 그런 결과가 나오는지 단계별 설명 패널
- "면접 모범 답안" 탭 별도 제공

## 이 섹션 완료 후 면접 답변 가능 질문

- "클로저를 설명하고 활용 예시를 보여주세요" → closure
- "이벤트 루프란 무엇인가요? Promise와 setTimeout의 실행 순서는?" → event-loop
- "this 바인딩이 결정되는 규칙을 설명해주세요" → this-binding
- "프로토타입 기반 상속이란?" → prototype
- "async/await와 Promise의 차이는?" → async-patterns
